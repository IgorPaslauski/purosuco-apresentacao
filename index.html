O compilador

Da fonte à saída

AMOSTRADINHO TROPA Programa {
AMOSTRADINHO SEMPRE_FOI_ASSIM VOLTA_NADA Main() {
MANDA_AI("RECEBA!");
}
}

A linha marcada é a chamada. Ela segue para as quatro fases abaixo.

Tokens

Corta o texto em pedaços, na ordem do arquivo. Ainda não tem hierarquia.

MANDA_AIKeyword
(OpenParen
RECEBA!String
)CloseParen
;Semicolon

Árvore

Os pedaços ganham estrutura. A string fica dentro da chamada.

ExpressionStatement
└ Call MANDA_AI
  ├ Name MANDA_AI
  └ Literal RECEBA!

Três endereços

Cada linha faz uma coisa. O texto vira param. A chamada vira call.

func Main() -> VOLTA_NADA
    param "RECEBA!"
    call MANDA_AI, 1
    return

Saída

A VM executou a chamada.

RECEBA!

O compilador

Erro, otimização e execução

exemplo.suco:1:21: erro PS003 — QUE PAPINHO É ESSE?
 1 | NUMERO idade RECEBA "vinte";
   |                     ^^^^^^^ Esperava NUMERO, recebeu PAPO.

O circunflexo marca só "vinte". Esperava número, recebeu texto.

Dobra de constantes

2 vezes 3 já vale 6. O1 troca a conta antes de executar.

NUMERO x RECEBA 2 * 3;

O0 · trecho

t0 := 2 * 3
vira

O1 · trecho

t0 := 6

Três saídas

A VM executa o código intermediário. C e C# traduzem a árvore.

AST → IR → VM

VM roda

Construtor para no IR.

AST → C

C c · roda --nativo

Não traduz construtor nem método de instância.

AST → C#

C# cs · roda-cs

Traduz construtor. O que falta é outro caso.

A extensão

VS Code / Cursor

TextMate pinta o arquivo.

purosuco-lsp

Completa, explica e marca o erro. É o mesmo analisador do compilador.

Zed

Tree-sitter pinta o arquivo.

Os dois editores falam com o mesmo servidor.
